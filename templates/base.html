WIDS: Wandering Intrusion Detection System

“See Your Network. Detect the Threats.”

Problem Statement

WIDS provides students and small teams with a clear view of local network activity, stored security events, and rule-based detections. The interface is designed for practical investigation rather than raw terminal-style alert handling.

SMART Objectives Achieved

  • 1. Monitoring Demo: Provides live interface counters and bounded ping/ARP/local-port discovery alongside clearly labeled sample inventory.
  • 2. Rule-Based Detection: Evaluates live-compatible events and generated scenario events using configured port-scan, host-scan, connection-attempt, bandwidth, and unauthorized-service rules.
  • 3. Dashboard: Shows live/subnet collection results, sample inventory, traffic snapshots, and an illustrative protocol breakdown; packet inspection is not claimed.
  • 4. User Authentication & Profile: Secure user registration, credential authentication, role-based profile management, and session logout.
  • 5. Relational Database Logging: Network events, security alerts, and system activities are persisted and queryable in a relational database.
  • 6. Controlled Scenario Evaluation: Dedicated Scenario Testing Lab allows testing controlled traffic scenarios and documents detection latency, verdicts, and limitations.

Documented System Limitations

  • Packet payload capture and protocol inspection are not implemented; protocol and traffic charts may remain illustrative or interface-derived.
  • Scenario results are generated test inputs evaluated by the database-configured rule thresholds and time windows; they do not represent observed incidents.
  • Device vendor, operating system, role, and open ports are unknown unless a future collection component supplies them.
  • The application does not send network traffic, block devices, or inspect encrypted payloads.
